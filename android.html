MC_启动器 Android 版

Android 手机启动器使用说明

新手教程

1. 安装与首次启动

  • 安装 Android APK。首次打开时按提示授予所需权限。
  • 首次下载游戏需要网络连接；请保持网络畅通，并预留足够的存储空间。
  • 启动器会读取本页发布版本，并从 Mojang 官方清单下载对应的 Minecraft 正式版。

2. 选择登录方式

  • 离线登录：输入一个 3 至 16 位的玩家名即可，不需要正版账号。
  • 正版登录：使用已购买 Minecraft Java 版的 Microsoft 账号登录。
  • 此版本只提供正版账号与离线登录。

3. 下载与启动

  • 选择正式版并点击下载/启动。游戏文件和对应的 Java 运行环境会自动准备。
  • 初次下载 Java 运行环境可能需要一些时间；下载中请勿强制关闭应用。
  • 进入游戏后会自动连接 a8.okmc.cc:45301。

故障排除

提示找不到 Java 运行环境，或启动时闪退

  • 连接稳定的网络，然后重新下载并启动该 Minecraft 正式版，让启动器安装所需的 Java 运行环境。
  • 若下载中断，请保持网络后再次尝试；启动器会重试获取发布版本信息。
  • 较新的 Minecraft 版本需要 Java 25 和兼容的 64 位设备。旧款 32 位设备可尝试较早的游戏版本。
  • 仍无法启动时，请在启动器中导出最新崩溃日志并提交给发布者。
